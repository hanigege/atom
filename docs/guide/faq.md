# 常见问题

### 有的设备不走代理

先在这台设备上查询一个国外域名，看返回的是不是 FakeIP（默认 `28.x.x.x`）：

- **返回的是真实 IP**：这台设备没有用 atom 做 DNS。常见原因：
  - 浏览器开了「安全 DNS」（DoH），在浏览器设置里关掉；
  - 主路由通过 IPv6 RA 下发了别的 DNS，设备优先用了 IPv6 的 DNS。关掉主路由的 IPv6 DNS 下发，或者在主路由上把它也指向 atom；
  - 设备手动设置了 DNS。
- **返回的是 FakeIP，但打不开网站**：流量没有到达 atom。检查主路由上 FakeIP 网段的静态路由；单网卡旁路由还要检查主路由防火墙会不会丢掉「invalid」状态的包（见 [安装和接入](install.md#单网卡旁路由)）。

atom 无法拦截浏览器的 DoH 和设备自己设置的 DNS：客户端的网关是主路由，这些查询根本不经过 atom。

### 改了规则，有的网站还是走老的出口

- 代理组之间的改动立即生效；
- 在直连和代理之间切换的域名，要等客户端的 DNS 缓存过期，最多 5 分钟。清一下客户端的 DNS 缓存，或者重启浏览器，可以马上生效。

详见 [规则 · 改动后多久生效](rules.md#改动后多久生效)。

### 支持 IPv6 吗

目前不支持 IPv6 FakeIP：走代理的域名只返回 IPv4 地址。

### 所有国外网站都打不开

一般是兜底分组或「默认代理」组里没有可用的节点。打开概览页看节点和节点组的状态；没有节点时，组里的流量会全部被拒绝，不会悄悄改走直连。

### 可以装在 OpenWrt 或 Docker 里吗

不行。atom 需要一台完整的 Linux（Debian、Ubuntu 或 Alpine），用 systemd 或 OpenRC 管理服务，并且要能修改 nft 规则和策略路由。虚拟机可以，Docker、LXC 容器不行。

### 第三方 Clash 面板里看到的节点名是一串 ID

atom 在内核配置里用不会变的内部 ID（比如 `n-1a2b3c4d`）做节点和组的标签，改名后已有的绑定不会失效。请用 atom 自己的面板查看名称。
